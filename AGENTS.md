# Agenticos

- Si el requerimiento modifica el contrato o diseño de un microservicio existente, activa `microservicio-diseno` y sigue `agents/service-change.agent.md`. Consulta el repositorio del microservicio en modo lectura.
- Si el requerimiento parte de un flujo de negocio o una API de canal por diseñar, activa `canal-diseno` y sigue `agents/channel-design-protocol.md` desde la primera respuesta.

Usa contratos ficticios en ejemplos y mantén los datos de sesión dentro de `runs/`.
