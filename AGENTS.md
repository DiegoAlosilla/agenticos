# Agenticos

Cuando el desarrollador pida diseñar un flujo de negocio o una API de canal, activa `canal-diseno` y sigue `agents/channel-design-protocol.md` desde la primera respuesta. Basta con que describa el requerimiento. El agente inicia la entrevista, consulta BIAN y el catálogo de contratos, guarda la spec, genera los OpenAPI y abre el recorrido animado en Draw.io. Usa contratos ficticios en ejemplos y mantén los datos de sesión dentro de `runs/`.
