# Editor de diseño de canal

Inicia el fork con `npm run channel:editor`. El panel derecho separa **Contratos** (Swagger y repositorio Business), **BIAN** (catálogo y referencia de la figura) y **Recorrido** (animación, criterios y evidencia). Las figuras y los contratos vinculados se guardan en el `.drawio`. [Demo de préstamos](channel-design.md)
